# Learning AI in Public

I am an AI PM learning the full AI stack by building, not by watching courses.

Every unit in this repo follows the same format:

1. **Concept** — plain language notes, no jargon
2. **Code** — a working demo you can run yourself
3. **Application** — where this shows up in real products
4. **Test** — questions to check if it actually stuck

No courses. No certificates. Just building and teaching.

## How to use this repo

Start at Unit 01. Read the concept notes. Run the demo. Answer the test questions before looking at the answers.

Each unit builds on the previous one. Skipping ahead works but you will feel the gaps.

For the demos you need:

```bash
pip install groq chromadb
export GROQ_API_KEY='your-key-here'
```

Get a free Groq API key at console.groq.com. No credit card needed.

## Why I built this

People ask me how I learned AI. The honest answer is I did not take a course. I just talked to the model like a person, built things, broke them, and figured out why they broke.

This repo is that process made structured. If you can follow it start to finish, you will understand the full AI stack better than most people selling courses about it.

The best way to learn is to teach. This is me teaching.
