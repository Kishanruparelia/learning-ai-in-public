Unit 01

What is an LLM?

Core mechanism
Next word predictor. Not a brain, not a search engine, not a database. Predicts the most plausible continuation of your input.
Key insight
More context narrows the prediction. 10,000 people to 1. Better context, better output. Always.
What it is NOT
Not a search engine Not a database Not a brain Frozen in time Pattern matcher only

Unit 02

Tokens

What they are
3 to 4 characters each. 100 words = ~130 tokens. Input and output both cost tokens.
Context window
The bathtub. Fixed size. When full, old messages fall out. The model cannot see them anymore.
Three things tokens affect
Cost at scale Memory length Speed $3 per million tokens System prompt = hidden tax

Unit 04

Hallucinations

FFCIL: Find Fakes In Claude's Logic
Factual Fabrication Context Instruction Logical
Type and fix
Factual : RAG
Fabrication : demand citations
Instruction : system prompt
Context : grounding rules
Logical : chain of thought
Root cause
Same mechanism as correct answers. The model has no signal for "I know this" vs "I am guessing." Not a bug. The nature of prediction.
